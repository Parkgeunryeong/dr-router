STEP 0 · 공공데이터포털 API 키 발급

1

회원가입 & 로그인

data.go.kr 가입. (팀에서 1명 계정으로 받아 키를 공유해도 되고, 각자 받아도 됨)

2

필요한 데이터 2개 활용신청

  • 검색창에 "건강보험심사평가원 병원정보서비스" → 활용신청
  • 검색창에 "국립중앙의료원 전국 응급의료기관 정보 조회 서비스" (E-Gen) → 활용신청
  • (선택) "전국 약국 정보 조회 서비스" → 활용신청

개발계정은 보통 즉시 승인, 일일 트래픽 제한(예: 1,000건)이 있습니다.

3

인증키 확인 → .env에 저장

마이페이지 → 오픈API → 인증키. 일반 인증키(Decoding) 값을 복사해서 .env에 넣으세요.

HIRA_API_KEY=여기에_심평원_Decoding_키
EGEN_API_KEY=여기에_E-Gen_Decoding_키
키가 2종류입니다 — Encoding(이미 URL인코딩됨) / Decoding(원본). 아래 코드처럼 requests의 params=로 넘길 땐 Decoding 키를 쓰세요. (Encoding 키를 params로 넘기면 이중 인코딩되어 인증 실패 — 가장 흔한 실수)

STEP 1 · 키부터 테스트 (curl)

코드 짜기 전에 키가 되는지 먼저 확인. (심평원 병원 목록, 서울 지역 50건)

# PowerShell / cmd / Git Bash 공통 (키는 Decoding 값)
curl "http://apis.data.go.kr/B551182/hospInfoServicev2/getHospBasisList?serviceKey=<키>&_type=json&pageNo=1&numOfRows=5&sidoCd=110000"

response.body.items.item 배열이 보이면 성공. resultCode가 00이면 정상입니다.

엔드포인트 버전 주의 — 경로의 hospInfoServicev2 버전 숫자는 바뀔 수 있어요. 안 되면 data.go.kr 상세페이지의 "End Point"를 그대로 복사해서 쓰세요.

STEP 2 · hira.py (심평원 병원 검색)

아래는 확인된 사양 기준 뼈대입니다. 확인완료 표시 외의 값은 data.go.kr 상세페이지 요청변수/출력결과 표에서 최종 확인하세요.

import os
from math import radians, sin, cos, asin, sqrt
from typing import List, Dict
import requests

from backend.config import HIRA_API_KEY

# ✅ 확인완료: base + operation (소스코드로 검증)
BASE = "http://apis.data.go.kr/B551182/hospInfoServicev2/getHospBasisList"

# 시도코드(숫자) — 일부. 전체는 HIRA 보건의료빅데이터개방시스템 코드조회
SIDO = {"서울": "110000", "부산": "210000", "대구": "220000",
        "인천": "230000", "광주": "240000", "대전": "250000",
        "경기": "310000", "전남": "360000", "세종": "410000"}

# 진료과목코드(dgsbjtCd) — 일부. ⚠ 코드값은 상세페이지에서 확인 후 채우기
DGSBJT = {"내과": "01", "신경과": "02", "정신건강의학과": "03",
          "외과": "04", "정형외과": "05", "소아청소년과": "10",
          "산부인과": "11", "안과": "12", "이비인후과": "13",
          "피부과": "14", "비뇨의학과": "15", "가정의학과": "23"}


def _haversine_m(lat1, lng1, lat2, lng2):
    """두 좌표 사이 거리(m). 좌표 없으면 None."""
    try:
        lat2, lng2 = float(lat2), float(lng2)
    except (TypeError, ValueError):
        return None
    if not lat2 or not lng2:
        return None
    R = 6371000
    dlat, dlng = radians(lat2 - lat1), radians(lng2 - lng1)
    a = sin(dlat / 2) ** 2 + cos(radians(lat1)) * cos(radians(lat2)) * sin(dlng / 2) ** 2
    return int(2 * R * asin(sqrt(a)))


def search_hospitals(dept: str, lat: float, lng: float,
                     sido: str = "서울", top: int = 5) -> List[Dict]:
    params = {
        "serviceKey": HIRA_API_KEY,   # ✅ Decoding 키
        "_type": "json",             # ✅ JSON 응답
        "pageNo": 1,                  # ✅ 확인완료
        "numOfRows": 50,              # ✅ 확인완료
        "sidoCd": SIDO.get(sido, "110000"),   # ✅ 요청변수명 확인완료
        "dgsbjtCd": DGSBJT.get(dept, ""),     # ✅ 요청변수명 확인완료
    }
    r = requests.get(BASE, params=params, timeout=5)
    r.raise_for_status()

    body = r.json().get("response", {}).get("body", {})
    items = (body.get("items") or {}).get("item", [])
    if isinstance(items, dict):   # 1건이면 dict로 옴 → list로 통일
        items = [items]

    out = []
    for it in items:
        # ✅ 응답필드 확인완료: yadmNm, addr, telno, clCdNm
        # ⚠ 좌표필드(XPos=경도, YPos=위도)는 출력결과 표에서 이름 확인
        out.append({
            "name": it.get("yadmNm", ""),
            "dept": dept,
            "distance_m": _haversine_m(lat, lng, it.get("YPos"), it.get("XPos")),
            "is_open": True,          # 운영시간은 상세API 필요 → 우선 True
            "phone": it.get("telno"),
        })

    out = [h for h in out if h["distance_m"] is not None]  # 좌표 있는 것만
    out.sort(key=lambda h: h["distance_m"])                # 가까운 순
    return out[:top]
왜 거리를 직접 계산하나? — 위치 반경 파라미터(xPos/yPos/radius)는 버전에 따라 제공 여부가 달라요. 그래서 시도로 1차 필터 → 좌표로 거리 계산·정렬이 안전합니다. 상세페이지에 radius 검색이 있으면 그걸 써도 됩니다.

STEP 3 · egen.py (응급실·약국)

E-Gen은 실시간 응급실 가용병상이 강점이에요. 확인필요 오퍼레이션·파라미터는 data.go.kr 상세페이지에서 확정하세요. (아래는 표준 사양 기준 뼈대)

import requests
from typing import List, Dict
from backend.config import EGEN_API_KEY

# ⚠ 확인필요: base/operation 을 상세페이지 End Point로 확정
# 응급실 실시간 가용병상 (표준 사양)
EGEN_RTBED = "http://apis.data.go.kr/B552657/ErmctInfoInqireService/getEmrrmRltmUsefulSckbdInfoInqire"


def search_emergency(lat: float, lng: float,
                     sido: str = "서울특별시", sgg: str = "") -> List[Dict]:
    params = {
        "serviceKey": EGEN_API_KEY,   # Decoding 키
        "_type": "json",
        "STAGE1": sido,               # ⚠ 시도명(문자). 파라미터명 확인필요
        "STAGE2": sgg,                # ⚠ 시군구명(문자). 확인필요
        "pageNo": 1,
        "numOfRows": 20,
    }
    r = requests.get(EGEN_RTBED, params=params, timeout=5)
    r.raise_for_status()
    body = r.json().get("response", {}).get("body", {})
    items = (body.get("items") or {}).get("item", [])
    if isinstance(items, dict):
        items = [items]

    out = []
    for it in items:
        # ⚠ 응답필드명 확인필요: dutyName(기관명), dutyTel3(응급실전화),
        #    hvec(응급실 가용병상수), wgs84Lat/wgs84Lon(좌표)
        out.append({
            "name": it.get("dutyName", ""),
            "dept": "응급의학과",
            "distance_m": 0,          # 좌표 있으면 hira._haversine_m 재사용
            "is_open": True,          # 응급실은 24시간 → True
            "phone": it.get("dutyTel3"),
        })
    return out
E-Gen은 꼭 상세페이지에서 확정 — 공식 명세(요청변수·출력결과 표)를 코드 연구로 확인하지 못했어요. STEP 1처럼 curl로 먼저 한 번 호출해서 실제 응답 필드명을 눈으로 보고 코드에 반영하세요. (약국은 별도 서비스 getParmacyListInfoInqire 계열)

STEP 4 · search 노드 연결

backend/agent/nodes/search.py에서 위 두 함수를 묶습니다. (이미 뼈대가 있어요)

def search_hospitals(state):
    depts = state.get("departments", [])
    loc = state.get("location", {}) or {}
    top_dept = depts[0]["name"] if depts else None

    hospitals = []
    if top_dept and loc.get("lat") and loc.get("lng"):
        hospitals += hira.search_hospitals(top_dept, loc["lat"], loc["lng"])
        hospitals += egen.search_emergency(loc["lat"], loc["lng"])
    state["hospitals"] = hospitals
    return state

XML만 오고 JSON이 안 옴_type=json 파라미터 빠짐
