02 · Setup

프로젝트 세팅 방법

GitHub에서 프로젝트를 받아 내 컴퓨터에서 실행하기까지. 처음 한 번만 하면 됩니다. (Windows 기준)

사전 준비 — Python 3.11+, Git, VS Code, GitHub 계정. 그리고 팀장이 보낸 저장소 접근 초대를 수락해두세요.

최초 세팅 (한 번만)

1

저장소 받기 (clone)

원하는 폴더에서 (경로에 한글 없게):

git clone https://github.com/<팀계정>/dr-router.git
cd dr-router
2

가상환경 만들기

python -m venv venv
venv\Scripts\activate      # PowerShell / cmd
# 활성화되면 줄 앞에 (venv) 가 붙습니다
PowerShell에서 activate가 막히면 한 번만: 
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
3

패키지 설치

pip install -r requirements.txt

사용할 LLM/임베딩에 따라 requirements.txt의 주석 처리된 줄(예: langchain-openai)을 풀고 다시 설치하세요.

4

환경변수(.env) 설정

copy .env.example .env     # (mac/linux: cp .env.example .env)

.env 파일을 열어 API 키를 채웁니다. (이 파일은 git에 올라가지 않음)

키발급처
HIRA_API_KEY공공데이터포털 → 심평원 병원정보서비스
EGEN_API_KEY공공데이터포털 → 국립중앙의료원 E-Gen
LLM_API_KEY사용하는 LLM 제공처(OpenAI/Anthropic 등)
5

(최초 1회) RAG 인덱스 구축

python -m backend.rag.build_index

data/departments/의 진료과 문서를 임베딩해 chroma_db/에 저장합니다. (문서가 아직 없으면 건너뛰어도 됨)

6

서버 실행

uvicorn backend.main:app --reload

브라우저에서 http://localhost:8000 접속 → 프론트 화면이 뜨면 성공. API 확인: http://localhost:8000/api/health

여기까지 되면 세팅 완료! 이제 각자 역할 페이지로 가서 작업을 시작하면 됩니다.

Git 작업 방식 (feature 브랜치 + PR)

main은 항상 돌아가는 상태로 유지합니다. main에 직접 push 금지 — 반드시 브랜치를 파서 작업하고 PR로 합칩니다.

1

작업 시작할 때마다 최신 main 받기

git checkout main
git pull
2

내 작업 브랜치 생성

git checkout -b feat/taejun-rag   # feat/<이름>-<작업>
3

작업 → 커밋 → 올리기

git add .
git commit -m "feat(rag): Chroma 적재 스크립트 추가"
git push -u origin feat/taejun-rag
4

GitHub에서 PR 생성 → 리뷰 → main 병합

Pull Request를 올리면 팀원이 확인하고 main에 합칩니다. 병합 후 브랜치는 삭제.

네이밍 규칙

종류예시
브랜치feat/geunryeong-agent, fix/geon-api-timeout
커밋feat(agent): ..., fix(api): ..., docs: ...
충돌 주의 — "공유 계약" 파일
agent/state.py(박근령), api/schemas.py(최건), backend/main.py(박근령), requirements.txt(전원, 추가만). 이 파일을 바꿀 땐 먼저 팀에 공지하세요. 특히 State/schemas는 프로젝트 초반에 확정하고 자주 안 건드리는 게 핵심.

자주 쓰는 명령어

git status                 # 현재 상태
git pull                   # 최신 받기
git checkout -b feat/...    # 브랜치 생성
git add . && git commit -m "..."
git push                   # 올리기
git branch                 # 내 브랜치 목록
